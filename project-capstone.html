Project Description

AI Team Assistant is a capstone project developed in collaboration with PT. Jalin Mayantara Indonesia as part of a 6-person team. The platform is an AI-powered team collaboration tool that helps organizational teams retrieve knowledge, answer internal queries, and streamline team workflows through a RAG (Retrieval-Augmented Generation) pipeline backed by a Pinecone vector database and automated with n8n workflow automation. My responsibility was building the complete student-facing frontend using React 18, integrating it with the AI backend services, and ensuring a smooth, intuitive user experience for team members interacting with the assistant. The platform is deployed live at capstone.karyatech.web.id.

AI Assistant Interface

Built the core conversational interface where team members can query the AI assistant in natural language. The interface handles real-time response streaming, conversation history, and contextual follow-up questions — connected to the RAG pipeline backend.

Knowledge Base Integration

Integrated the frontend with a Pinecone vector database to enable semantic search across the team's internal knowledge base. Users can upload documents and query relevant content through the assistant with contextually accurate retrieval.

Workflow Automation with n8n

Connected the frontend to n8n-powered automation workflows that handle backend task orchestration — including document processing triggers, notification flows, and integration with external team tools — presented through a clean and accessible UI.

Team Dashboard & Activity Overview

Developed a team dashboard that provides an overview of recent assistant interactions, knowledge base activity, and team usage statistics — helping team leads monitor adoption and identify frequently queried topics.

Process

Requirement Alignment with Client & Team

Collaborated with PT. Jalin Mayantara Indonesia and the 5-person capstone team to align on product requirements, user stories, and technical architecture. Defined the frontend scope, component structure, and API contract with the backend team.

React 18 Frontend Development

Built the full frontend from scratch using React 18, leveraging concurrent features and hooks for performant state management. Structured the codebase for maintainability with clear component boundaries and separation of concerns across features.

RAG Pipeline & Pinecone Integration

Integrated the frontend with the team's RAG pipeline and Pinecone vector database through API calls, handling response streaming for the chat interface, document upload flows, and semantic search result rendering.

n8n Workflow Connection

Connected UI actions to n8n automation workflows via webhook triggers, enabling backend processes (such as document ingestion and notification dispatch) to be initiated directly from frontend interactions in a seamless user experience.

Deployment & Cross-Team QA

Coordinated the frontend deployment to capstone.karyatech.web.id and participated in cross-team quality assurance sessions to verify end-to-end feature correctness, API reliability, and UI responsiveness before the final client presentation.
