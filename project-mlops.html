Project Description

This project is an end-to-end MLOps pipeline built to predict food commodity prices in East Java, covering 7 commodities across multiple time horizons. The system was designed to automate the full machine learning lifecycle — from data ingestion and feature engineering through to model training, deployment, and monitoring — following MLOps best practices. A total of 42 models were trained across the 7 commodities, exposed via a FastAPI service, containerized with Docker Compose, and deployed with CI/CD automation using GitHub Actions and DVC on DagsHub. System health and model performance are monitored in real time through a Prometheus and Grafana observability stack.

Automated Data Pipeline

Built an automated data ingestion and preprocessing pipeline that collects food commodity price data, handles missing values, and engineers time-series features — ensuring the training data is always consistent and reproducible across runs.

Multi-Commodity Model Training

Trained 42 forecasting models across 7 food commodities, applying feature engineering techniques tailored for time-series prediction. Experiments and model versions were tracked and managed using DVC on DagsHub, ensuring full reproducibility.

FastAPI Serving & Docker Deployment

Packaged and exposed the trained models through a FastAPI REST API service, containerized using Docker Compose for consistent deployment across environments. The service handles prediction requests per commodity with structured JSON responses.

CI/CD & Monitoring Stack

Implemented a CI/CD pipeline using GitHub Actions to automate testing, model re-training triggers, and deployment. System observability is handled by Prometheus for metrics collection and Grafana for real-time dashboard monitoring of model performance and API health.

Process

Problem Scoping & Architecture Design

Defined the forecasting problem scope — 7 food commodities, time-series prediction, and multi-model management requirements. Designed the overall MLOps architecture covering data, training, serving, and monitoring layers before implementation began.

Data Ingestion & Feature Engineering

Built the automated data ingestion pipeline to collect and preprocess historical food price data from East Java. Applied time-series feature engineering including lag features, rolling statistics, and calendar-based variables to improve model signal quality.

Model Training & Experiment Tracking

Trained 42 models across 7 commodities, using DVC on DagsHub for experiment tracking and versioning. Compared model configurations to select the best-performing model per commodity based on evaluation metrics.

API Development & Containerization

Developed a FastAPI service to serve predictions, then containerized the full stack using Docker Compose — ensuring the API, model artifacts, and dependencies are packaged together for consistent and reproducible deployments.

CI/CD Automation & Observability Setup

Configured GitHub Actions for automated testing and deployment triggers. Set up Prometheus to collect API and model metrics, and built Grafana dashboards to visualize system health and monitor prediction performance over time.
